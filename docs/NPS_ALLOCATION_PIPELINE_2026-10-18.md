# 국민연금 국내주식 비중 추정 자료

2026-10-18 신규 동작. 기존 시세/API/실시간 캐시를 바꾸지 않고 미리 계산한 정적 자료를 Toss 국민연금 화면에 공급한다. 별도 사이트의 검증된 공시·13F 명세를 이관하고, 일별 재계산에 적합하도록 시장 관측을 같은 Yahoo 시계열로 통일했다.

## 공개 계약

- `static/data/nps/summary.json`: 약 15KB의 요약. `schemaVersion:1`, 계산 버전 `snapshotVersion`, 생성시각 `generatedAt`, 실제 공통 종가일 `marketDate`, 공시 기준 `baseline`, 모형 `inputs`·`assetBaseline`, 결과 `result`·`sensitivity`, 13F 범위 `filing`, 관측 출처 `market`·`sources`, 가정 `warnings`.
- `filing.detailsFile`: `holdings-<snapshotVersion>.json`. 눌러서 볼 때만 읽는 552개 항목 명세. `snapshotVersion`과 `marketDate`가 요약과 같아야 한다. 보유량·보고달러값·가격·수익률·직접 평가/잔여 추정 구분 및 주식분할·기업행동 감사 자료를 포함한다.
- 원화 자산/조정액은 **조 원**, 13F 금액은 **달러**다. 수익률/비중은 0~100 단위이며 목표와의 차이는 `%p`다. `adjustment>0`은 현 모형의 국내주식 증가 방향, `<0`은 축소 방향이며 실제 예상 매매액이 아니다.
- 생성시각·원공시 기준일·제출일·시장 관측일을 서로 대신하지 않는다. 화면 방문은 공급자를 호출하지 않는다.

## 최초 공개 관측과 계산

공식 기금은 2026-07-31 기준 총 1,684.1732조 원, 국내주식 418.5577조 원, 해외주식 623.6862조 원이다. SEC 13F는 2026-06-30 보유분/08-13 제출의 552개 항목, $155,079,663,358이다. 공식 자료 링크 및 해석은 `scripts/nps/config.json`에 보존한다.

2026-10-16의 실제 재조회에서 546개 항목, 보고금액 99.5353%의 가격을 검증했다. SPGI·CTVA 분할기업, WBD·EA 현금합병, AVB 주식교환, OXYWS 워런트는 직접 평가에서 제외해 해외주식의 잔여액에 포함한다. SCCO의 1.012 주식배당은 SEC 검증 조건과 날짜가 일치할 때만 수량에 반영한다.

6월 보고 수량을 검증 가능한 분할로 맞추고 7월 말 가격으로 평가한 직접 추정액을 공식 해외주식에서 차감한다. 이 부분은 종목별 7/31→현재 조정종가 수익률, 잔액은 ACWI 조정종가 수익률을 적용한다. 13F를 해외주식 총액에 추가하지 않는다. 달러 수익률을 계산한 뒤 외화 노출의 미헤지 85%에 환율을 한 번 적용한다. 배당은 조정종가에 포함되므로 현금배당을 다시 더하지 않는다. 세부의 `currentValueUSD`는 배당 재투자 수익률을 적용한 이론값, `currentMarketValueUSD`는 분할 반영 수량×현재 가격이다.

일별 갱신에서는 USD/KRW를 Yahoo의 동일 시계열 양 끝값으로 통일했다. 7/31 1,420.6000→10/16 1,340.9500으로 −5.6068%다. 이전 별도 사이트에서 사용한 다른 일별 환율 제공자의 1,442.5227→1,334.5789와 다르므로 동일 날짜라도 결과가 달라진다. 국내채권은 이전 두 날짜의 수동 금리 근사 대신 **114260.KS(KODEX 국고채 3년)와 148070.KS(KOSEF 국고채 10년)의 조정종가 수익률을 50:50**으로 사용한다. 해외채권은 BNDW, 단기는 연 3%, 대체는 연 6%의 실제 경과 일수 누적+해외주식 수익률×0.25다. 모든 비율은 실제 운용을 대체하는 가정으로 표시한다.

최초 일별 방법의 결과는 **22.5538515920%, 목표 20.8%보다 1.7538515920%p 높음, 내부 조정액 −27.9715597494조 원**이다. 최신 파일의 버전과 수치는 `--check`를 기준으로 삼는다. 이전 사이트의 정확한 이관 seed는 [seed-summary.json](evidence/nps20261018/pipeline/seed-summary.json)에 별도로 보존한다.

## 자동 갱신과 보존

`.github/workflows/update-nps.yml`는 미국의 월~금 장이 종료되고 일별 FX 바까지 완료된 **UTC 화~토 01:30 / 한국시간 화~토 10:30**에 실행한다. Github 일정은 지연될 수 있으며 정해진 시각의 갱신 성공을 보장하지 않는다. 수동 실행 `force=true`는 같은 시장일을 재확인한다. 새 비밀 키·유료 모델/LLM 호출은 없다. 기본 `GITHUB_TOKEN`의 저장소 쓰기 권한으로 검증한 두 파일을 함께 main에 커밋한다. Toss의 기존 공개 정적 CDN 경로로 읽으므로 실시간 API 재배포에 의존하지 않는다.

1. 마지막으로 **완료된 UTC 날짜** 이전의 ACWI/BNDW/USD-KRW/KOSPI/국채 ETF 여섯 시계열을 확인한다. 양수 종가·조정종가와 정확한 7/31 기준값이 모두 있는 공통 날짜를 선택한다. 각 시장 종료시각은 다르다. 미래 관측·이벤트는 제외한다.
2. SEC 제출 목록을 확인한다. 신규 13F나 수정본이 있으면 `review-required`와 보고일을 알리고 기존 검증 수량의 시장 가격만 갱신한다. SEC 확인 실패는 새로 확인했다고 표기하지 않고 마지막 검증일을 유지한다.
3. 552개 보고 종목을 최대 4개 동시 연결, 요청당 최대 12초/2회 및 전체 기본 600초로 조회한다. 보고일 수량×역사 가격과 SEC 금액을 0.5% 이내로 대조해 잘못된 티커·분할 기준을 차단한다.
4. 보고금액 평가 범위 99% 미만, 이전 직접 평가 항목의 새 실패, 잘못된 통화/중복 CUSIP/비정상 금액/누락 기준일/5일 초과 공통 날짜/전체 시간 초과는 공개를 중단한다. 이전 파일·원래 날짜·생성시각을 보존한다. 실패를 0이나 임의 수익률로 채우지 않는다.
5. 불변 상세 파일을 먼저 쓰고 요약 포인터를 원자 교체한다. 이전 버전을 보존해 열린 화면의 상세 조회가 다른 버전과 섞이지 않는다. 더 오래된 종가일의 덮어쓰기는 거절한다.

**공식 월별 기금 잔고와 신규 13F 종목 매핑을 자동 승인하지 않는다.** 이 입력은 새 원공시·단위·CUSIP·기업행동을 확인해 `scripts/nps/config.json`을 갱신해야 한다. 자동화 범위는 공시 수량을 이용한 시장 추정치 갱신 및 SEC 새 제출 탐지다. 국내주식 실제 구성·배당 재투자, 공시 이후 매매, 급여지급/보험료, 실제 환헤지, 비달러 환종 및 대체투자 공정가치 평가의 차이는 남는다. SAA/TAA 합산 상단과 목표 지수는 조건부 시나리오다.
