# 모바일 UI·UX 개선 구현 — 2026-09-21

## 반영 내용
- 599px 이하 화면에 제목·본문·보조정보 크기와 좌우 여백을 적용했습니다.
- 관심종목 상단 요약을 줄이고 정렬을 선택기로 바꿨습니다. 관리 메뉴를 헤더로 이동하고 이름·가격·수익률 중심의 행으로 정리했습니다.
- 종목분석 상단의 검색·추천·비교 관리 영역을 비교종목 관리 대화상자로 옮겼습니다. 임시 선택, 최대 6개 제한, 적용·취소, 뒤로가기, 검색 요청 취소를 지원합니다.
- 관심종목과 비교종목은 별도로 유지합니다. 선택된 비교종목은 작은 상태 표시로 보입니다.
- 기간은 1개월·3개월·1년과 추가 선택기로 정리했습니다. 직접 기간 입력 및 오류 메시지를 유지합니다.
- 주요 조작 영역은 최소 44px, 검색 입력은 16px 글꼴을 사용합니다. 대화상자는 내부 스크롤과 safe-area를 반영했습니다.

## 검증
- Python 회귀 테스트 152개 통과.
- 프런트엔드 단위 테스트 6개 통과.
- 생성 번들 재빌드 및 JavaScript 구문 검사 통과.
- 모바일 CI에 비교 선택의 적용·취소 및 관심종목 독립성 검증을 추가했습니다.
- 운영 화면의 직접 브라우저 점검은 사용량 한도로 자동 승인 검토에서 거절되어 실시하지 못했습니다. 실제 단말의 키보드·확대 글꼴·시각적 완성도는 별도 확인이 필요합니다.

## 남은 확인
- 320/360/390/430px 및 큰 글꼴에서 줄바꿈과 첫 콘텐츠 위치.
- iOS Safari 및 Android 브라우저에서 키보드가 열린 관리창의 적용 버튼 접근성.
- 장문 종목명, 비교 0/6개, 새로고침 후 빈 선택 유지.
- 시세 시각 표기의 원본 데이터·표시 변환 일관성은 별도 과제로 유지합니다.
