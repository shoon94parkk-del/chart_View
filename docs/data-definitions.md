# Chart View 데이터 정의

## 시각의 구분

- `generatedAt`/수집 시각: 애플리케이션이나 GitHub Actions가 데이터를 가져와 캐시를 만든 시각이다.
- `asOf`/원자료 기준일: 거래소 가격 또는 경제지표 관측치 자체가 가리키는 날짜다.
- 화면의 ‘정상 수집’은 요청 성공을 뜻한다. 원자료가 당일 값이라는 뜻은 아니다.

## 비교 차트 수익률

- 기본 기준: Yahoo Chart 조정주가(`adjusted_close`) 일봉.
- 계산: `(마지막 유효 조정주가 / 첫 유효 조정주가 - 1) × 100`.
- API는 `priceBasis`, `requestedPeriod`, `startDate`, `endDate`, `observations`를 함께 반환한다.
- `1달`은 달력상 조회 프리셋이며 `20일 수익률`과 같은 개념이 아니다.
- 공급자가 조정주가 배열을 주지 않으면 종가(`close`)를 사용하고 `priceBasis`로 알린다.

## 밸류에이션

- API의 `fieldMeta`가 각 필드의 실제 선택 소스, 기준일, 기간, 직접값/재계산 방식을 설명한다.
- `trailingPE`, `trailingEPS`, `psr`는 TTM 기준이다.
- `forwardPE`, `forwardEPS`는 공급자 예상 필드다. FY1·NTM 등 정확한 회계기간을 독립 확인하지 못한 경우 `provider forward period (not independently verified)`로 반환한다.
- `pbr`, `bookValue`는 최근 공시 또는 가격/자본/주식수로 재구성할 수 있다.
- 화면에서 서로 다른 PER은 동일 계산이라고 가정하지 않는다. 공급자 현재 비율과 역사적 재구성 비율을 구분한다.

## 역사적 PER/PBR 밴드

- 과거 조정 가격에 당시 TTM 희석 EPS 또는 당시 자본·주식수를 결합한 근사 재구성치다.
- 실제 공시일이 없을 때 결산일 이후 45일을 자료 이용 가능 시점으로 가정한다.
- PER 0.5~200, PBR 0.05~100 범위 밖은 통계에서 제외하며 API의 `excluded`에 개수를 제공한다.
- ‘마지막 재구성 값’은 마지막 유효 관측일의 값이다. 실시간 현재 비율이라는 뜻이 아니다.
- 백분위는 선택 기간 전체 분포에서의 상대 위치이며 본질가치나 매수·매도 신호가 아니다.

## EPS 변화율과 주가 변화율 차이

- 계산: `EPS 30일 변화율(%) - 조정주가 30일 수익률(%)`.
- 단위: 퍼센트포인트(`%p`).
- EPS와 가격의 기준일을 함께 표시한다.
- 값이 크다는 것은 두 변화율의 차이가 크다는 관측이다. 시장이 실적을 잘못 반영했다는 확정 판단은 아니다.

## 투자판단 보조

- 가치, 수익성, 전망, 모멘텀 축에서 확인된 조건을 표시한다.
- 같은 축의 지표 여러 개가 충족돼도 독립된 여러 판단 축으로 과대 집계하지 않는다.
- `필수 재무지표 5/5 제공`은 데이터 존재 범위다. 최신성·정확성·투자 매력도 100%를 뜻하지 않는다.
- 화면에 없는 사업·정책·공시·수급 위험까지 없다는 뜻으로 해석하지 않는다.
