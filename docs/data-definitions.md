# Chart View 데이터 정의

## 시각의 구분

- `generatedAt`/수집 시각: 애플리케이션이나 GitHub Actions가 데이터를 가져와 캐시를 만든 시각이다.
- `asOf`/원자료 기준일: 거래소 가격 또는 경제지표 관측치 자체가 가리키는 날짜다.
- 화면의 ‘정상 수집’은 요청 성공을 뜻한다. 원자료가 당일 값이라는 뜻은 아니다.

## 비교 차트 수익률

- 기본 기준: Yahoo Chart 조정주가(`adjusted_close`) 일봉.
- 계산: `(마지막 유효 조정주가 / 첫 유효 조정주가 - 1) × 100`.
- API는 `priceBasis`, `requestedPeriod`, `startDate`, `endDate`, `observations`를 함께 반환한다.
- `1달`은 달력상 조회 프리셋이며 `20일 수익률`과 같은 개념이 아니다.
- 공급자가 조정주가 배열을 주지 않으면 종가(`close`)를 사용하고 `priceBasis`로 알린다.

## 밸류에이션

- API의 `fieldMeta`가 각 필드의 실제 선택 소스, 기준일, 기간, 직접값/재계산 방식을 설명한다.
- `trailingPE`, `trailingEPS`, `psr`는 TTM 기준이다.
- `forwardPE`, `forwardEPS`는 공급자 예상 필드다. FY1·NTM 등 정확한 회계기간을 독립 확인하지 못한 경우 `provider forward period (not independently verified)`로 반환한다.
- `pbr`, `bookValue`는 최근 공시 또는 가격/자본/주식수로 재구성할 수 있다.
- 화면에서 서로 다른 PER은 동일 계산이라고 가정하지 않는다. 공급자 현재 비율과 역사적 재구성 비율을 구분한다.

## 역사적 PER/PBR 밴드

- 과거 조정 가격에 당시 TTM 희석 EPS 또는 당시 자본·주식수를 결합한 근사 재구성치다.
- 실제 공시일이 없을 때 결산일 이후 45일을 자료 이용 가능 시점으로 가정한다.
- PER 0.5~200, PBR 0.05~100 범위 밖은 통계에서 제외하며 API의 `excluded`에 개수를 제공한다.
- ‘마지막 재구성 값’은 마지막 유효 관측일의 값이다. 실시간 현재 비율이라는 뜻이 아니다.
- 백분위는 선택 기간 전체 분포에서의 상대 위치이며 본질가치나 매수·매도 신호가 아니다.

## EPS 변화율과 주가 변화율 차이

- 계산: `EPS 30일 변화율(%) - 조정주가 30일 수익률(%)`.
- 단위: 퍼센트포인트(`%p`).
- EPS와 가격의 기준일을 함께 표시한다.
- 값이 크다는 것은 두 변화율의 차이가 크다는 관측이다. 시장이 실적을 잘못 반영했다는 확정 판단은 아니다.

## 투자판단 보조

- 가치, 수익성, 전망, 모멘텀 축에서 확인된 조건을 표시한다.
- 같은 축의 지표 여러 개가 충족돼도 독립된 여러 판단 축으로 과대 집계하지 않는다.
- `필수 재무지표 5/5 제공`은 데이터 존재 범위다. 최신성·정확성·투자 매력도 100%를 뜻하지 않는다.
- 화면에 없는 사업·정책·공시·수급 위험까지 없다는 뜻으로 해석하지 않는다.

## Screener company context (2026-09-29)
- `industry`: KRX KIND 상장법인목록의 ‘업종’ 원문.
- `mainProducts`: KRX KIND 상장법인목록의 ‘주요제품’ 원문.
- 두 필드는 기술적 스크리너와 동일한 일별 payload에 포함되지만 가격/기술지표와 달리 기업 분류 설명 데이터다.
- `mainProducts`는 ‘매출액 1위 품목’으로 해석하지 않는다. 사업보고서 매출 비중 근거가 연결되기 전까지 대표/주요 제품·서비스로만 표시한다.

## DART 사업보고서 매출구조 (2026-09-29)
- API: `GET /api/business-report?ticker=005930.KS&name=삼성전자`
- 한국 6자리 상장 종목만 대상이며 해외 종목은 조회하지 않는다.
- `DART_API_KEY`가 설정돼 있으면 OpenDART 공시검색/원문 API를 우선 사용하고, 없거나 실패하면 저빈도 DART 공개 공시뷰어 fallback을 사용한다.
- 최신 사업보고서의 표에서 명시적인 매출/매출액 열이 확인된 경우에만 `items`, `topItem`, `share`를 반환한다.
- 제품/사업부문별 표를 확실히 찾지 못하면 `available=false`로 반환하며 KRX 주요제품을 매출 1위로 추정하지 않는다.
- 서버 메모리 캐시는 7일, Toss 요청 캐시는 1일이다. 공시 원문 링크(`sourceUrl`)를 항상 함께 제공한다.

## 직접 관계 근거 API (2026-09-29)
- API: `GET /api/relationship-evidence?ticker=005930.KS&name=삼성전자`
- 한국 KOSPI/KOSDAQ 종목만 대상이다.
- 최근 회사 뉴스 중 기존 뉴스 서비스가 해당 종목 직접 관련으로 검증한 기사만 사용한다.
- 다른 KRX 상장사명이 명시되고, 같은 기사 근거 구간에 `공급계약/납품/수주/발주/고객사/채택/탑재/계약체결` 등 강한 상업관계 키워드가 함께 있을 때만 관계를 반환한다.
- 단순 업종 동반 상승, 산업 키워드 동시 언급, 이름이 없는 ‘글로벌 고객사’ 같은 표현만으로는 직접관계를 만들지 않는다.
- 반환 항목에는 상대 상장사, 관계 유형, 기사 제목, 제공처, 게시시각, 원문 URL을 포함한다.
- 결과가 없으면 `available=false`이며 프런트는 기존 산업상 연관 후보만 유지한다.

## OpenDART 성능 경로 (2026-09-29)
- 운영 기본 흐름은 로컬 `static/data/dart_corp_codes.json`의 종목코드→DART 고유번호 매핑 → OpenDART 정기공시 검색 → 해당 접수번호의 DART 공시뷰어에서 주요제품/매출 섹션만 조회하는 방식이다.
- 전체 `corpCode.xml`을 런타임에서 매번 내려받거나 전체 사업보고서 ZIP을 우선 다운로드하지 않는다.
- 삼성전자 기준 개선 전 계측: corpCode.xml 212.795초, 전체 원문 ZIP 46.426초, 전체 경로 265.835초.
- 개선 후 GitHub 러너 첫 호출 2.684초, 서버 메모리 캐시 재호출 0.0초 수준.
- Render 운영 실측: 첫 호출 4.147초, 재호출 0.084초.
- 삼성전자 2025 사업보고서에서 DX 부문 56.3%를 사업부문 매출 1위로 확인한다. 주요 제품은 별도 detail로 유지하며 개별 제품 매출로 오인하지 않는다.
- 내부거래 제거 행(△ 표기)은 음수 조정값으로 해석해 비중/총액 검증에 반영하고, 사용자 매출 항목 목록에서는 제외한다.
