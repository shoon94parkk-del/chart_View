## Reddit용 영문

### Title
I built a free stock comparison web app for charts + valuation metrics in one place

### Body
I built **Chart View** because I was tired of switching between different sites just to compare price performance and valuation metrics.

It is now available as a free public beta.

Current features:
- Compare up to 6 Korean or US stocks
- Relative performance charts
- Forward P/E, trailing P/E, P/B, P/S, EV/EBITDA and ROE
- Market overview and stock screening
- No sign-up required
- Mobile-first UI

The goal is not to generate buy/sell signals. It is mainly a fast comparison tool to help narrow down which stocks deserve deeper research.

I would really appreciate feedback on broken layouts, missing data, confusing UX, or features that would actually help when comparing stocks.
