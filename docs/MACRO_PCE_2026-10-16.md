# PCE·근원 PCE와 발표일 검증

## 변경 범위

기존 선택형 물가 캐시에 PCE·근원 PCE를 추가한다. `/api/macro`의 기존16개 지표·요약, 홈 데이터와 PICK/LAB 계산·기록·선정·화면 노출은 변경하지 않는다. 기존 PCEPI·절사평균 PCE 요약도 유지한다.

- `scripts/pce_release_data.py`: 공식 BEA XLSX의 `U20304-M`, 계정 `DPCERG`/`DPCCRG`를 읽는다. 표 정의·2017=100·SA 메타데이터, 중복·연속 월·값을 검증한다. 다운로드32MiB/ZIP멤버64MiB 한도를 적용하며 프록시·TLS 기본값을 유지한다.
- `scripts/generate_inflation_release_cache.py`: PCE는 YoY·MoM 모두 SA이며 같은 월 지수를12개월/1개월 전과 비교한다. 72개 원지수에서60개 변화율을 저장하고 가짜 NSA 필드는 만들지 않는다. 한 파일을 두 지표가 공유한다. 앱 요청 중 외부 제공자 호출은 없다.
- 같은 수집기는 확인된 공식 발표보다 오래된 CPI/PPI 응답을 정상 최신 데이터로 승인하지 않는다. BLS 대체 조회도 실패하면 마지막 정상 값과 확인 시각을 보존한다.
- 공식 BEA 현재 발표 링크를 따라 관측월·실제 발표 시각을 확인한다. 뉴스 확인 실패 시 XLSX의 명시적 발표 날짜만 보존하며08:30이나 자정 시각을 만들지 않는다. 미래·퇴행·불완전 자료는 이전 정상 캐시를 유지한다.
- 공식 BEA PIO 일정의 UTC/ET·서머타임을 보존한다. 일정 JSON에 없는 관측월은 추정하지 않는다. 실패한 BEA 확인은 개별 unavailable/stale 및 전체 partial로 기록한다.
- 기존6시간 정기 갱신에 통합한다. BEA 최초 실패가 기존 BLS 갱신을 차단하지 않도록 CI는 필수4종+선택PCE2종을 검증하며 알 수 없는 ID·중복·잘못된 기준을 거부한다.

## 실제 데이터 확인

2026-10-16 확인 기준:

| 지표 | 관측월 | 공식 발표 | YoY / MoM (공식1자리 반올림) |
|---|---|---|---|
| CPI / 근원 CPI | 2026-09 | 10-14 | 3.7 /0.6, 2.6 /0.3 |
| PPI / 근원 PPI(식품·에너지 제외) | 2026-09 | 10-15 | 6.3 /1.3, 5.0 /0.7 |
| PCE / 근원 PCE | 2026-08 | 09-30 | 3.4 /0.3, 3.0 /0.2 |

10월 발표와10월 관측치는 다르다. 10월 CPI·PPI 관측치의 예정 발표는11월10일·13일이며, 다음 PCE 발표는10월29일이다. 일정 변경 가능성을 유지한다. 지수 계산값은 현재 수정본일 수 있으므로 최초 발표값으로 부르지 않는다.

출처: [BEA 지수 파일](https://apps.bea.gov/national/Release/XLS/Underlying/Section2All_xls.xlsx), [8월 PCE 발표](https://www.bea.gov/news/2026/personal-income-and-outlays-august-2026), [BEA 공식 일정](https://apps.bea.gov/API/signup/release_dates.json), [9월 CPI](https://www.bls.gov/news.release/archives/cpi_10142026.htm), [9월 PPI](https://www.bls.gov/news.release/archives/ppi_10152026.htm).

이번 저장 캐시는 기존4종 전체를 그대로 보존해 잠정치 각주도 유지한다. 실제 새 수집본과 기존4종의 모든 지수·YoY·MoM 값이 동일함을 별도로 비교했다. BEA 두 시계열의72개 지수는 FRED 공개값과 모두 일치했다. FRED는 이 교차 검증에만 사용했으며 새 PCE 운영 입력은 직접 BEA 자료다.

## 예상치 비교와 남은 조건

공식 BLS/BEA 실제 지수는 시장 예상치를 제공하지 않는다. 기존 기업 `/api/consensus`도 경제지표 예상치가 아니다. 승인된 예상치 제공자·발표 전 동결 이력이 없어 운영 예상치는 비워 두며 수치를 만들지 않는다. Toss 화면의 선택적 비교 규격은 최초 발표 actual, 발표 전 공개·수집된 expected, 같은 관측월/SA·NSA/YoY·MoM/%를 검증한다. 현재 수정된 지수와 최초 발표를 혼합하지 않는다.

실제 유료 공급자 계약·재배포 권한과 키 설정은 별도 확인 사항이다. 신규 서비스/비용/키/임의 딥링크는 추가하지 않는다. 테스트·PR·배포 결과는 해당 PR의 최종 검증 기록을 기준으로 한다. 실제 Toss Android/iOS Sandbox는 별도 미검증이다.

재현: `python -m pytest -q`, `python scripts/build_frontend_bundle.py --check`, `python scripts/generate_inflation_release_cache.py`. 마지막 명령은 공식 외부 데이터 수집이므로 날짜별 결과가 달라질 수 있다. 단위 테스트는 주입된 고정 자료로 실행된다.
