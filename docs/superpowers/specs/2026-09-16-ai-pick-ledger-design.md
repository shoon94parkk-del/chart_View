# AI PICK 누적 원장 UI 설계

## 목표
`종목 발굴` 안에 `시장 스크리너`와 `AI PICK 기록` 두 개의 하위 탭을 제공하고, AI PICK 기록은 장기 누적에 적합한 고밀도 원장형 UI로 표시한다.

## 정보 구조
- 상위 탭 `종목 발굴`은 유지한다.
- 내부에 `시장 스크리너` / `AI PICK 기록` 세그먼트 탭을 추가한다.
- 기존 스크리너 DOM은 그대로 보존하고, AI PICK 모듈이 외부 래퍼와 하위 탭을 주입한다.
- 홈 `ChartView AI PICK 3`는 오늘의 3개만 유지한다.
- 홈 `성과 기록 →` 클릭 시 별도 정적 페이지 대신 `/?tab=screener&view=ai-picks`로 이동하고, 메인 탭과 하위 탭이 자동으로 열린다.
- 기존 `/static/recommendations.html`은 새 위치로 리다이렉트해 북마크 호환성을 유지한다.

## AI PICK 기록 화면
### KPI
상단에 작고 동일한 크기의 KPI 4개를 배치한다.
- 누적 추천일
- 누적 추천 건수
- 수익 구간 비율
- 평균 수익률

### 도구 영역
한 줄 또는 모바일 2줄로 압축한다.
- 종목명/코드 검색
- 기간: 전체 / 최근 7일 / 최근 30일
- 성과: 전체 / 수익 / 손실
- 정렬: 최신순 / 수익률 높은순 / 최고수익률 높은순 / 점수 높은순

### 원장
기본 화면은 여러 종목을 동시에 스캔할 수 있는 표 형태다.
열: 추천일, 순위, 종목, 추천가, 현재가, 수익률, 최고수익률, 점수.
- 행 클릭/키보드 Enter로 상세 영역을 펼친다.
- 상세에는 등급, 상태, 추천 사유만 표시한다.
- 추천 사유는 기본 목록에서는 감춰 정보 밀도를 높인다.
- 한 번에 60개를 표시하고 `더 보기`로 60개씩 추가한다.

### 모바일
- 표를 억지로 가로 스크롤하지 않는다.
- 각 행을 2~3줄짜리 압축 카드 행으로 재배치한다.
- 첫 줄: 날짜/순위 + 종목명 + 현재 수익률
- 둘째 줄: 추천가 → 현재가 + 최고수익률 + 점수
- 상세는 데스크톱과 동일하게 펼침 방식이다.

## 디자인 원칙
- 기존 Chart View의 흰 배경, 회색 테두리, Toss 계열 타이포/간격, 파란 포인트를 유지한다.
- 큰 카드 그림자와 과도한 그라디언트는 쓰지 않는다.
- KPI는 숫자 중심, 원장은 테두리와 행 hover만으로 구분한다.
- 수익률 색상은 기존 프로젝트 규칙대로 양수 빨강, 음수 파랑을 유지한다.
- 터치 타깃은 최소 40px 수준을 확보한다.

## 데이터
- `/static/data/ai_recommendations.json`: 누적 성과 원장 데이터의 단일 소스.
- `/static/data/ai_daily_rankings.json`: 누적 추천일 KPI 계산 보조.
- 기존 이름↔종목코드 검증 로직은 그대로 사용한다.

## 실패/빈 상태
- 데이터 로딩 실패 시 원장 영역에 재시도 가능한 오류 메시지를 표시한다.
- 검색/필터 결과가 0개면 필터 초기화 버튼을 표시한다.
- 데이터 자체가 없으면 첫 추천이 쌓이면 표시된다는 빈 상태를 보여준다.

## 호환성
- 기존 시장 스크리너 기능, 필터, 클릭 이벤트를 변경하지 않는다.
- 기존 `/static/recommendations.html` 주소는 새 종목 발굴/AI PICK 화면으로 리다이렉트한다.
- URL `?tab=screener&view=ai-picks`로 직접 진입할 수 있다.

## 테스트 기준
- 종목 발굴 내부 하위 탭 2개가 생성된다.
- 기본은 시장 스크리너, URL view=ai-picks 또는 홈 링크에서는 AI PICK 기록이 열린다.
- KPI와 원장 8개 핵심 필드가 렌더링된다.
- 검색/기간/성과/정렬/더보기가 동작한다.
- 모바일 700px 이하에서 가로 스크롤 없이 압축 행으로 보인다.
- 기존 스크리너 DOM과 이벤트가 유지된다.
