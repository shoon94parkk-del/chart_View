# V41 — MY 관심 허브

## 목표

관심종목이 홈의 보조 카드에 머물지 않도록 `관심` 탭을 실제 개인화 허브로 승격한다. 홈은 TOP 3 뉴스 요약만 유지하고, 전체 관심종목 뉴스는 `관심 > 내 종목 뉴스`에서 탐색한다.

## 구현

- `관심` 화면에 `관심종목 / 내 종목 뉴스` 전환을 추가했다.
- 기존 `chartview-watchlist-v1` 저장 형식과 최대 20개 규칙을 그대로 사용한다.
- 관심종목 화면은 큰 카드 대신 조밀한 행형 리스트로 정리했다.
- 내 종목 뉴스는 `/api/personalized-news`의 기존 종목별 `groups`를 재사용해 전체 피드를 만든다.
- 제공처 호출을 새로 추가하거나 유료 API를 도입하지 않는다.
- 전체 / 종목별 필터 chip을 제공한다.
- `최신순 / 관련도순` 정렬을 제공한다. 화면에는 불명확한 숫자 중요도 대신 `실적 / 계약·수주 / M&A / 주주환원 / 규제·법률 / 시장 의견 / 기업 뉴스` 이벤트 유형을 우선 표시한다.
- 최초 10건을 보여주고 `뉴스 더 보기`로 10건씩 추가한다.
- 각 뉴스에서 단일 종목 상세와 원문으로 이동할 수 있다.
- 홈 `관심종목 핵심 뉴스`에는 `전체보기 →`를 추가해 MY 뉴스 화면으로 직접 이동한다.
- 홈 TOP3 구조와 V40 뉴스 로딩 안정성은 유지한다.

## UX 결정

- 최근 5거래일 미니차트는 홈의 보조 컨텍스트로만 유지하고 전체 뉴스 피드에는 기본 노출하지 않는다. 기사 반응으로 오해할 가능성을 줄이기 위함이다.
- V41 전체 뉴스 피드는 기사 제목/종목/이벤트 유형/출처/시간/원문에 집중한다.
- 관련도순은 기존 서버 score의 상대 정렬에만 사용하며 숫자 점수를 사용자에게 표시하지 않는다.

## 사용자 데이터 보존

- 관심목록, 비교목록, 최근 본 종목, 종목명 localStorage 형식을 변경하지 않는다.
- V41은 기존 `watchlist_v30.js`가 소유한 관심목록 상태를 읽어 표시한다.
- 테스트는 격리된 Playwright context에서 수행하므로 실제 사용자의 저장값을 변경하지 않는다.

## 검증

`tests/v41_my_hub.cjs`에서 390×844 Chromium 환경으로 다음을 검증한다.

- 관심 탭 진입 후 V41 허브 설치
- 관심종목 3개 유지
- 관심종목 / 내 종목 뉴스 전환
- 종목별 그룹 기사 전체 피드 병합
- 이벤트 유형 배지
- 종목별 필터
- 최신순 / 관련도순 상태
- 홈 뉴스 `전체보기 →`에서 MY 뉴스로 직접 이동
- 390px 가로 오버플로 없음
- 브라우저 page error 없음

기존 `mobile_smoke.cjs`와 `app_release_stage12.cjs`도 함께 실행한다.
