## 1단계 A — 상세 멈춤·상태·결측값

- V39.3의 observer-driven 상세 JS를 활성 로딩 경로에서 제거했다. CSS는 시각 호환을 위해 유지한다.
- 상세 대상은 `ChartViewState.detail`에 명시적으로 저장하고 요청마다 seq를 증가시킨다.
- 상세 A→B 전환 시 이전 fetch를 abort하고, 모든 API 완료 후 `isCurrentDetail(symbol, seq)`를 재확인한다.
- 상세 닫기 역시 seq를 증가시키고 fetch를 abort하므로 늦은 응답이 화면을 다시 열 수 없다.
- 상세 진입은 비교목록을 변경하지 않는다.
- 비교 버튼은 `비교 중 / 비교에 추가 / 비교목록 관리` 세 상태만 사용한다.
- localStorage 키/형식은 기존과 동일하게 유지한다. 저장된 `[]`은 사용자 의도로 보존하고 key가 없을 때만 기본 비교목록을 적용한다.
- 숫자 공통 정규화는 정상 0과 결측/비정상 값을 구분한다. 결측은 `—`, 계산 분모 0은 `계산 불가`로 처리할 수 있게 상태를 구분한다.
- ROE/배당률을 값 크기로 추정해 100배 하는 로직을 제거했다.

## 1단계 B — 뉴스 20개·부분 실패·비동기 안정화

- 관심종목 20개 모두 `/api/personalized-news` 조회 대상이 된다.
- 서버 provider 호출은 전체 요청을 통틀어 `BoundedSemaphore(4)`로 제한하고 5분 캐시를 유지한다.
- 종목별 그룹 상태를 `success / no_news / error`로 반환한다.
- 기사 제목·출처·발행시각·원문/상세 액션을 먼저 표시한다.
- 미니차트는 같은 종목 진행중 요청을 공유하며 후속 로딩한다. 실패해도 기사 카드는 유지한다.
- 관심목록 변경/새로고침 시 AbortController와 load sequence를 같이 사용한다.
- 기본 카드에는 중요도 등급만 보이고 숫자는 제거했다. `왜 중요?`는 `이벤트 참고 설명`으로 바꾸고 제목 기준 분류임을 명시했다.
- 뉴스 제공처 설정 실패 시 사용자에게 환경변수 이름을 노출하지 않는다.

## 2단계 C — 단일 상세와 비교 화면 분리

- 홈/관심/뉴스/스크리너 상세가 모두 `__openStockDetail` 단일 경로로 들어간다.
- 단일 상세가 열리면 기존 비교 차트/비교용 종목 요약을 같은 결과처럼 노출하지 않는다.
- 상세 헤더: 뒤로가기, 이름/티커/시장, 현재가·거래기준, 관심, 비교상태.
- 상세 핵심지표는 1달 수익률/FWD PER/EPS 30일 변화 3개로 제한한다.
- 차트는 기존 `/api/compare`의 기간 시작 대비 수익률 시계열을 사용하고 `1달 수익률 차트`라고 명시한다.
- 재무·밸류는 단일 종목용 세로 목록, 기준 상세는 터치 가능한 `<details>`로 제공한다.
- 비교 화면은 `비교종목 관리 → 기간/차트` 순서로 압축하고 기존 `stock-brief-v8`를 비교 차트 위에서 반복 노출하지 않는다.
- 기간 버튼/직접 날짜 설정은 차트 헤더로 이동하되 기존 DOM id와 이벤트를 유지한다.

## 2단계 D — 홈·관심·밸류·스크리너·시장

### 홈/관심
- 홈은 시장 → 관심 최대4 → 핵심뉴스 최대3 → 추가 시장정보 순서를 유지한다.
- 모바일 관심종목은 큰 카드 대신 행형으로 압축했다.
- 긴 종목명은 2줄, 가격은 말줄임 없이 전체 표시한다.
- 종목별 거래 기준일 + `1달` 표기를 가까이 둔다.
- 상승 빨강 / 하락 파랑을 사용하고 부호/기존 화살표를 함께 유지한다.
- 홈 시장은 대표 4개를 먼저 표시하고 나머지는 명시적 더보기로 연다.

### 밸류 비교
- 기본 열은 `종목 / 현재가 / FWD PER / PER / ROE`로 축소한다.
- 기존 나머지 지표는 `지표 선택 · 전체 지표 보기`에서 접근 가능하다.
- 정렬 버튼은 `FWD PER 낮은순/높은순`처럼 대상 지표를 명시한다.
- 빈 문자열·NaN·Infinity는 null로 정규화해서 0처럼 정렬하거나 표시하지 않는다.
- 출처/기준은 `기준 보기` details로 터치/키보드 접근 가능하다.

### 종목발굴
- 적용 조건 요약과 `조건 초기화`를 추가했다.
- 액션명은 `비교에 추가 / 상세 보기 / 관심`으로 구분한다.
- 5일·60일 수익률을 평균거래대금 셀에서 성과 셀로 이동한다.
- 기존 계산식과 preset 조건은 변경하지 않았다.

### 시장
- 기존 13개 지표 계산은 변경하지 않는다.
- `fresh/stale/STALE` 사용자 표현을 `정상 수집/이전값`으로 변경한다.
- 상세 카드는 금리/위험/유동성/경기 순서로 묶는다.
