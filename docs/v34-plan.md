# Chart View V34 — 종목분석 모바일 UX 개편

## 목표
모바일에서 종목분석 화면을 열었을 때 설정 UI가 화면 대부분을 차지하지 않도록 정리하고, 종목 선택 → 기간 선택 → 차트 확인 흐름을 짧게 만든다.

### 핵심 UX 원칙
- 첫 화면에서 분석 결과가 빨리 보여야 한다.
- 자주 쓰는 선택은 바로 보이고, 드물게 쓰는 상세 설정은 접는다.
- 기존 차트/밸류에이션/투자판단 기능과 API는 유지한다.
- V34 1차에서는 새 데이터 API를 만들지 않고 레이아웃·동선 안정화에 집중한다.

## V34 1차 범위

### 1. 종목 선택 영역 압축
- 종목 검색 입력창과 `+` 버튼 높이 축소
- 선택된 종목 칩을 한 줄 중심의 컴팩트 영역으로 정리
- 추천 종목은 기본 접힘 유지
- 관심종목에서 진입한 경우 선택 종목이 상단에서 즉시 확인되어야 함

### 2. 분석 탭 명확화
- `차트 / 밸류에이션 / 투자판단`을 하나의 segmented control로 유지
- 모바일에서 한 줄 고정
- 현재 선택 탭의 대비를 명확히 유지

### 3. 기간 선택 단순화
- 기본 노출: `1달 / 3달 / 6달 / YTD / 1년 / 전체`
- 시작일·종료일 입력은 `직접 기간 설정`을 눌렀을 때만 펼침
- 프리셋 기간 선택 시 별도 `적용` 버튼 없이 즉시 반영
- 직접 기간을 설정할 때만 `적용` 버튼 표시

### 4. 첫 화면 정보 밀도 개선
- 불필요한 카드 여백과 중복 설명 축소
- 기간 컨트롤 아래 차트가 가능한 한 빨리 시작되도록 구성
- 데이터 출처 문구는 차트 하단 또는 보조 정보로 이동

### 5. 앱 이동 규칙 유지
- 관심종목 → 종목분석 진입 후 Android 뒤로가기 시 관심종목으로 복귀
- 종목발굴 → 종목분석 진입 후 뒤로가기 시 종목발굴로 복귀
- 하단 5개 메뉴는 한 줄 고정 유지

## 후속 V34 2차 후보
1차 UX 안정화 후 검토:
- 종목분석 상단 `한눈에 요약` 카드: 현재가 / 1달 수익률 / 핵심 밸류 / 컨센서스
- 종목별 마지막 사용 분석 탭 기억
- 공유/딥링크용 URL 상태 반영

## 모바일 합격 기준
384×824 Samsung Internet 기준:
- 하단 5개 탭 한 줄 유지
- 종목 검색/선택 영역 가로 overflow 0
- 분석 3개 탭 한 줄 유지
- 프리셋 기간 버튼 한 줄 또는 의도된 compact wrap
- 기본 상태에서 시작일/종료일 필드는 숨김
- 프리셋 클릭 시 차트가 즉시 갱신
- 차트 상단이 기존 V33 대비 유의미하게 위로 올라옴
- 브라우저 pageerror 0
- 기존 관심종목/스크리너/시장 네비게이션 회귀 없음
